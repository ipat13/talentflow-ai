🚀 SOLUÇÃO RÁPIDA - PowerShell Bloqueado

ERRO ENCONTRADO:
"File C:\Program Files\nodejs\npm.ps1 cannot be loaded because running scripts is disabled on this system"

📋 SOLUÇÃO 1: USAR CMD (MAIS FÁCIL)

Passo 1: Pressione Windows + R
Passo 2: Digite cmd e pressione Enter
Passo 3: No CMD, execute:
cd C:\talentflow-ai\talentflow-ai
npm install
npm run dev

🔧 SOLUÇÃO 2: CORRIGIR POWERSHELL

Passo 1: Abra PowerShell como Administrador
(Clique direito → Executar como administrador)
Passo 2: Execute:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Passo 3: Digite S quando perguntar
Passo 4: Feche e reabra o PowerShell

⚡ SOLUÇÃO 3: SCRIPT AUTOMÁTICO

Passo 1: Clique direito em INSTALL_AND_START.bat
Passo 2: Selecione "Executar como administrador"
Passo 3: Digite S se pedir permissão
✅ APÓS RESOLVER:
1. As dependências serão instaladas (2-5 minutos)
2. O servidor iniciará em http://localhost:3000
3. Teste o dropdown em: /dashboard
💡 DICA: Use o CMD (Solução 1) - é mais rápido e não tem bloqueios!
