# 🚀 TalentFlow AI - Recrutamento Inteligente

O **TalentFlow AI** é uma plataforma de recrutamento de próxima geração que utiliza a IA da **DeepSeek** para automatizar a triagem de currículos e sourcing de candidatos.

## ✨ Funcionalidades
- **DeepSeek AI Integration:** Análise semântica de currículos com Match Score em tempo real.
- **Sourcing Inteligente:** Integração preparada para extração de dados do LinkedIn.
- **Arquitetura Escalável:** Middleware refatorado com o padrão *Chain of Responsibility* no Next.js 16.
- **Interface Dark Mode:** Dashboard focado em experiência de utilizador (UX) profissional.

## 🛠️ Tecnologias
- Next.js 16, TypeScript, Tailwind CSS, Firebase Auth, DeepSeek API.
